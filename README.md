
# Invicta

An archived frontend project for a gift-card marketplace, built with Nuxt and Vue.

I worked on the frontend, implementing multiple pages, interactive components, responsive layouts and animated 3D card visuals.

## Technologies

- Nuxt 2 and Vue 2
- SCSS
- Three.js
- Vuex
- JavaScript

## Project details

The frontend includes:

- Multiple marketplace pages and layouts
- Interactive gift-card visuals using Three.js
- Shared application state with Vuex
- Route middleware
- Responsive layouts and interactive components

The code also contains modules for working with product, user and other application data.

## Project status

This is an older client project.

The original demo is no longer available, and I'm working on restoring a standalone frontend version.

Some functionality may depend on APIs and backend services that are no longer accessible.

## Running locally

```bash
git clone https://github.com/OleksiiReznichenko/Invicta.git
cd Invicta
npm install
npm run dev
```

The application uses an older Nuxt 2 setup, so some dependencies may require a compatible Node.js environment.
